# 《观象悟道》国画风格规范

艺术底线：**一卦一象，一象一境，一境一理，一理一用。**

目标不是 64 张普通 AI 插画，而是统一笔墨语言、哲学意境和出版辨识度的原创国画系列。统一的是艺术语言，不是构图模板。

## 1. 四种风格类型

| 类型 | 适用主题 | 卦例 |
|---|---|---|
| 工写结合 · 青绿山水 | 开阔、向上 | 乾、泰、晋、丰 |
| 文人水墨 · 静观修身 | 修养与思辨 | 艮、谦、蒙、观 |
| 苍润山水 · 险境叙事 | 艰险与韧性 | 屯、坎、蹇、困 |
| 人物故事 · 国学叙事 | 六爻历史故事与人事 | 师、比、家人、同人 |

不同卦可以有不同气质：乾开阔雄浑，坤厚重宁静，坎险峻苍茫，离明亮通透，艮简静留白。

## 2. 统一视觉参数

| 维度 | 标准 |
|---|---|
| 画风 | 中国传统水墨，工笔与写意结合 |
| 色彩 | 青黛、石青、淡石绿、赭石、暖金、少量朱砂 |
| 纸张 | 宣纸肌理，淡墨晕染 |
| 留白 | 参考 35%–45%，依叙事灵活调整 |
| 构图 | 高远、平远、深远与散点透视 |
| 人物 | 中国古代文人、隐士、农人、工匠、历史人物 |
| 卦符 | 独立矢量 SVG，六爻程序化生成 |
| 书法 | 独立文字层，避免 AI 直接生成错误汉字 |
| 印章 | 独立图层，原创且经确认的印文 |
| 输出 | 无字主图、带字卡片、印刷版、数字版 |

## 3. 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| 青黛 | #273F52 | 主墨色、卦符默认色 |
| 石青 | #547A83 | 远山、水、层次 |
| 石绿 | #A2B4A1 | 草木、青绿设色 |
| 赭石 | #B58C69 | 土石、建筑、人物 |
| 朱砂 | #A74439 | 印章与点睛，少量 |

另可用暖金作点缀。

## 4. 三层合成模型

1. **Layer 1 国画主图**：只负责画面、意境、人物、山水、笔墨和色彩，不含文字与卦符。
2. **Layer 2 卦符矢量层**：由 `gxwd.renderer` 按六位二进制编码绘制，保证阴阳爻、内外卦和顺序准确。
3. **Layer 3 文字与印章**：使用审校后的中文文本，独立排版。

正式图卡、画册、印刷文件须保留分层源文件、版本与审校记录。

## 5. 创作流程

取象 → 立意 → 经营位置 → 笔墨设色 → 绘制与修订。先立意，后造境。
每卦至少保留：Master Artwork（无字主图）、Philosophy Card（图卡）、Editorial Illustration（适配插图）。

## 6. 艺术底线

- 卦象准确是前提，艺术含蓄是方法：不机械地"上面一团风、下面一团火"。
- 一幅画只表达一个核心意象与一个哲学命题。
- 图像模型的 prompt、参数、版本全部留档。

## 7. 应避免的错误

- 出现现代物品（电线、塑料、现代建筑、机械钟表等）。
- 错误的历史服饰、建筑、器物与场景。
- 颠倒上下卦关系，仍宣称为原卦象。
- 由 AI 生成的文字、卦符、印章。
- 64 幅使用同一构图模板，或风格漂移成"64 种 AI 风格"。
- 把经文以外的现代解读写成古典原文。
