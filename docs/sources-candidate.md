## 建议主编做的事

1. 看手头实物的封面、版权页、ISBN 页，确认属于上述哪一候选。
2. 在 `data/sources.json` 的 `ZYZY-RUAN` 条目里把 `publisher / isbn / page_system / edition` 换成实物信息。
3. 如果想把本项目的 `page` 字段改为"卷 + 页"二字段，告诉我，schema 和 CLI 都可以调。
4. 如果同时想保留多个底本（互校），加 `source_id = ZYZY-SHGJ` 或 `ZYZY-ZHBD` 等条目，`status` 置 `candidate`。
