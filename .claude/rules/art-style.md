# 艺术红线

- 一卦一象，一象一境，一境一理，一理一用；先立意，后造境。
- 统一的是艺术语言（纸张、笔墨密度、人物尺度、色彩），不是构图模板。
- 五色体系：青黛 #273F52、石青 #547A83、石绿 #A2B4A1、赭石 #B58C69、朱砂 #A74439（朱砂少量）。
- 留白参考 35%–45%，依叙事灵活调整。
- 三层合成：Layer 1 无字国画主图 / Layer 2 程序卦符 SVG / Layer 3 文字与印章。
- 图像模型不得绘制汉字、卦符或印章。
- 不得颠倒上下卦关系却仍宣称为原卦象；自然景物可艺术化，卦符结构必须精确。
- 避免现代物品、错误的历史服饰、建筑、器物与场景。
- 艺术 Agent 不得修改经文、卦序和编码，且只读已审定的卦义。
- 主图须保存模型、prompt、参数、版本；本轮未选定图像模型。
- 印文须原创且经人工确认；字体与书法授权须确认。
- 画面评分再高，卦象错误也须退回；卦象再准，构图呆板也不得出版。
